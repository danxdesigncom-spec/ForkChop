# Phase 5 — Accessibility and QA gate

**Branch:** `redesign/05-a11y` · **PR title:** `redesign: automated a11y suite`

Goal: turn *Accessibility audit v2* (canvas → Final designs → section 04) into automated checks that
block regressions, then do the manual pass that automation can't cover.

## 1. Playwright + axe
- `npm i -D @playwright/test @axe-core/playwright` and `npx playwright install chromium`.
- Add `playwright.config.ts`:
  - `webServer`: `npm run build && npm start` on port 3000, env
    `NEXT_PUBLIC_FEATURE_REDESIGN=true`. Leave Supabase unset; the app runs signed out.
  - Projects: `desktop-light`, `desktop-dark` (1440×900), `mobile-light`, `mobile-dark` (390×844).
    Dark = `colorScheme: 'dark'` **and** the cookie `fc-theme=dark`.
- Copy `docs/redesign/assets/a11y.spec.ts` to `tests/e2e/a11y.spec.ts`. It covers:
  - axe with tags `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa`, **0 violations**, on Home empty,
    Results with ingredients, Results page 2, the 24-ingredient popover, the basket (empty and
    filled), and the mobile basket sheet.
  - A keyboard walk: every tab stop has a visible focus indicator (a box-shadow or outline on the
    element or its `.field` wrapper).
  - Target size: every button, link and input is at least 24×24 unless it's an inline text link.
  - Dialogs: Esc closes and focus returns to the trigger.
- Keep Vitest for unit tests. Exclude `tests/e2e/**` in `vitest.config.ts`.
- Scripts: `"test:e2e": "playwright test"`.

## 2. CI
Copy `docs/redesign/assets/a11y.yml` to `.github/workflows/a11y.yml`. It runs on every PR to `main`
and uploads the Playwright report as an artefact. Make it a **required check** in the branch
protection settings once it passes.

## 3. Manual pass (record the results in `docs/redesign/A11Y-MANUAL.md`)
- VoiceOver on iPhone (Safari): add ingredients, change tab, change page, add a missing item, open the
  basket, switch Pickup / Delivery.
- VoiceOver on macOS (Safari) and NVDA on Windows (Firefox or Chrome): the same flow on desktop.
- Browser zoom to 200% and a 320px-wide window: nothing clipped, no horizontal page scroll (chip
  rows may scroll).
- `prefers-reduced-motion`: the sheet and popover don't animate.
- Windows High Contrast / forced-colors: focus ring and borders are still visible (add
  `@media (forced-colors: active)` fallbacks if needed).

## Acceptance checklist
- [ ] `npm run test:e2e` passes locally on all 4 projects.
- [ ] The CI workflow is green on the PR and marked required.
- [ ] `A11Y-MANUAL.md` records each manual check as pass or fail, with fixes linked.
